# filemap

- `CLAUDE.md`: agent rules and commands; keep it short
- `docs/tools.md`: MCP tool and event schemas
- `docs/GUIDE.md`, `docs/INSTALL.md`, `docs/SETUP.md`, `docs/PRIVACY.md`: the user guide, install, setup details and privacy
- `docs/images/`: README screenshots, from the made-up demo vault (`scripts/make_demo_vault.py`)
- `pyproject.toml`: project metadata, dependencies, `cortex` console script, ruff config
- `uv.lock`: locked dependency versions (generated by `uv sync`)
- `.python-version`: interpreter pin (3.12) for uv
- `README.md`, `LICENSE` (MIT), `SECURITY.md` (private vulnerability reporting), `.gitignore`, `.gitattributes`: repo basics
- `src/cortex/`: the Python package; one module per core concern plus `cli.py` and `mcp_server.py`
- `src/cortex/` core modules: `vault.py` (locked atomic writes, secret scan), `events.py` (the append-only event log), `catalog.py` (concept catalog), `levels.py` (states as folds over events), `planner.py` (Today), `session.py` (session lifecycle and close pipeline, git commit), `render.py` (cards, Today.md, escaping), `index.py` (FTS5 index), `doctor.py` (`cortex doctor` checks), `backup.py` (`cortex backup` zips), `cli.py` (Typer CLI), `mcp_server.py` (MCP tools)
- `tests/`: pytest, including `tests/fixtures/` (synthetic vaults only, never real data)

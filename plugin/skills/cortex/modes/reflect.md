# Reflect (weekly)
Call `cortex_reflect()` and walk the learner through it. By default keep it to about five minutes: steps 1, 1b and 11, then ask once "More (clusters, lint, portrait, claim upkeep)?". `/cortex reflect full` walks every step.
1. **Unconfirmed "about me" lines:** ask about them together, never one per message. With a multiple-choice question tool, put up to 4 lines per card (yes / no / skip; free text for "sometimes, when…" or an edit); otherwise show a numbered list the user answers like "1 yes 2 no". Split a line that holds two facts. Yes: patch with `user_confirmed=true`. No: `cortex_patch(id=page, op="reject", target=<the proposed line>)` (it goes to `## Not me`). Skip: leave it. Always allow "none of these, clear them".
1b. **Saved about you unasked (`saved.claims`):** ask about them the same way, 4 per card, and say which came from outside text. Yes: `cortex_log(kind="reconfirm", payload={claim: <id>, verdict: "yes"})`; it keeps the line as theirs only if this reflect has read no outside text (a source, a raw file, a past chat or a web page), else the line is asked again next time. No: `cortex_patch(id=page, op="retire", target=<claim id>)`. Mention `saved.changes` in one line; the user can run `cortex claims --unasked` for the full list with undo steps.
2. **Emerging clusters:** offer to create the suggested structure note.
3. **Fleeting inbox lines older than 7 days:** turn each into a permanent note, merge it into an existing one, or drop it.
4. **The week's learning numbers:** what moved, what's slipping, mistakes.
5. **`cortex_reflect(action="lint")`:** fix the orphans, broken links and long notes the learner cares about.
6. **Monthly self-portrait:** when `portrait.due`, follow the portrait step in `modes/second-brain.md`.
7. **What Cortex has no evidence of (`circling.items`):** show each text as it is. Ask whether to make it a loop, drop it on purpose, or mark it as done outside Cortex. Log the answer with `cortex_log(kind="circling", payload={key, verdict: loop|dropped|outside, reason?})`. For `loop`, also create it with `cortex_add(kind="loop")`. Never say they "avoid" anything.
8. **Price new claims (`surprisal.unpriced`):** for each, guess as a stranger who knows only "a university student" how likely the line is true of such a student, and log `cortex_log(kind="baseline", payload={claim: <id>, p0: 0.01-0.99})`. Tell the learner plainly that this is a generic model's guess, not a judgment of them.
9. **Generic claims (`surprisal.generic`):** for each, ask "This is true of almost anyone; keep it?". If they say no, retire it with `cortex_patch(id=page, op="retire", target=<claim id>)`.
10. **Contested claims (`bets.contested`):** for each, ask "Your answers stopped matching *<text>* around <first_miss>. Were you changing?" On yes, `retire` it or `revise` it to the new wording, with `until=<first_miss>`.
11. **Still true? (`bets.recheck`):** ask it for at most 2 of these claims and log each answer with `cortex_log(kind="reconfirm", payload={claim: <id>, verdict: yes|no})`. Offer to retire the claims in `bets.retire` (the user said no).
11b. **Grader spot-check (`spot_check`):** show each row (question, answer, verdict) and ask "Keep or flip?" in one card. Log `cortex_log(kind="spot_check", payload={event_id, verdict: correct|partial|wrong})`; a different verdict voids the grade and regrades it. The agreement rate shows in `cortex eval learning`.
End with `cortex_end`.

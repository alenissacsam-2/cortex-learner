# Project
`keepfold_find(kind="project")` → `keepfold_read(<project>)`.
- While working, record:
  - decisions: `keepfold_add(kind="decision")` with Context / Options / Decision / Consequences, linked to the project, plus `fields.options` (2–6 short choices that were on the table) and `fields.chosen` (the one picked);
  - concepts applied: graded `application`/`transfer` evidence when the learner actually used one;
  - progress: a journal line.
- Surface gaps: concepts in the project's `applies` that are Learning or Needs refresh.
